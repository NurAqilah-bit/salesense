# SalesAI HTML Prototype

This is a static HTML/CSS/JavaScript concept prototype.

## Open it locally
Double-click `index.html`.

## Put it online with GitHub Pages
1. Create a new GitHub repository, for example `salesai-prototype`.
2. Upload:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Open your repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
6. Click **Save**.
7. Wait a minute or two. GitHub will give you a public URL similar to:
   `https://YOUR-USERNAME.github.io/salesai-prototype/`

You can then turn that public URL into a QR code for your poster.

## Notes
- Sidebar tabs are clickable.
- Dashboard, Ask AI, Sales Data, Reports and Settings are separate views.
- AI answers and uploads are simulated for the concept prototype.
- No server or database is required.
